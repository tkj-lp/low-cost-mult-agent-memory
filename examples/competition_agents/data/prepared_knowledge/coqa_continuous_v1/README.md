# 连续任务预备知识库

2026年9月25日建立。本阶段完成预备建库；没有运行新的五轮模型答题实验，也不以建库结果宣称连续记忆链路已经修好。

## 数据与边界

- 来源：[官方连续问答验证集](https://downloads.cs.stanford.edu/nlp/data/coqa/coqa-dev-v1.0.json)。按官方文件顺序固定选择第一段会话的前五轮，没有按模型成绩挑选。
- 会话围绕小猫展开：颜色、住处、是否独居、同住者、姐妹的颜色。后续问题包含代词，必须承接本次运行产生的历史。
- 完整故事有1413个字符，逐字符保留，包括原有段落、空白和重复文字。数据集名称为 CoQA，原始故事来自其 MCTest 子集。
- 这是用于先打通连续流程的一篇故事，不是大规模知识库性能测试。
- 原文、在线问题、评分参考分别位于 `../../continuous_coqa_v1/knowledge_sources.json`、`../../continuous_coqa_v1/questions.json`、`../../continuous_coqa_v1/references.json`。抽取器只读取第一份文件。
- 原文文件 `../../continuous_coqa_v1/source.txt` 与官方故事的字符一致。没有按答案位置裁剪，没有使用官方答案生成知识库。

## 两种知识表示

文本侧：`text_documents.json` 保存整篇故事，读取时返回完整原文，不调用查询编码器，不建立文本向量、关键词或段落检索索引，不提前筛选答案段落。来源编号仅用于追溯原文，不承担查询排名。

超图侧：`facts.json` 与 `hypergraph.sqlite` 保存34条关系事实、70个节点、113条带角色的关联，以及事实来源。图中的搜索索引只供协议模式使用。原文中的人称指代只有在来源明确支持所属关系时才连接；不能确定的集体发言者仍保留为局部指称。

抽取模型固定为 `qwen3.7-flash-2026-07-15`，服务返回的模型名称与请求一致。抽取未一次通过：原始失败记录全部保存在 `extraction_cache`。按原文修正了来源编号、所属指代、对象与目的地混合、警告与否定混淆，并补齐遗漏的来源事实。完整记录见 `source_review.json` 与 `source_review_corrections.json`。

模型只抽取事实；程序负责构建实体、关系、限定条件和来源之间的连接。文本和超图来自同一篇故事。

## 验证与计时

`build_verification.json` 记录来源锚点、数据库完整性、文件一致性和无悬空关联检查。原文作为一个完整来源条目，清单中的条目覆盖率不代表全部语义已经被自动证明保留。

抽取、人工来源核对和建图全部属于预备工作，不计入之后的答题时间。清单中的离线秒数只记录最后一次恢复构建执行，不能当作全部抽取成本；之前六次抽取尝试的词元用量保留在缓存中。

旧知识库已从 `prepared_knowledge` 移出，停用备份位于 `../../retired_knowledge_20260925`。永久删除遭自动审批拦截，不能将其描述为已经删除。
