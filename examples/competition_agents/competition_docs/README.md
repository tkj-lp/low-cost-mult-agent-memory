## 技术报告整理建议

比赛要求的技术报告应覆盖：

```text
作品链接
设计方案
实现方案
运行效果 / 测试结果
演示视频
特色创新
```

现有 `项目设计文档.docx` 和 `01_系统设计文档.md` 可以支撑“设计方案”和“实现方案”，但不能单独替代完整技术报告。完整技术报告建议以 `03_实验报告框架.md` 为主体，合并以下内容：

```text
1. 作品链接：GitHub 仓库、分支或主分支链接
2. 设计方案：来自 01_系统设计文档.md
3. 实现方案：来自 04_方法部分.md 和关键代码说明
4. 运行效果：来自 run_result 中的结果和前端截图
5. 测试结果：来自指标评估页、CodeAct 运行结果和 openEuler 复现记录
6. 演示视频：填写最终视频链接
7. 特色创新：结构化协议、state_ref、hidden state 传递、超图共享记忆、experience memory、结果导入对比
```
