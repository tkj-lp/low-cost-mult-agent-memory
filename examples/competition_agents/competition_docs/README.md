# 比赛文档目录

本目录用于集中保存比赛交付相关文档。当前文档仍是草稿，系统设计、方法、接口和运行命令已经可以作为对齐材料；最终实验数据、截图和结论需要等 openEuler 24.03-LTS-SP3 环境重跑后再定稿。

## 文档阅读顺序

建议新同学或新对话按下面顺序阅读：

1. [../AGENT_WORK.md](../AGENT_WORK.md)

项目当前总进度、已完成/未完成、下一步优化、团队分工和接口冻结说明。

2. [../HYPERGRAPH_CONTRACT.md](../HYPERGRAPH_CONTRACT.md)

智能体主流程与超图记忆模块的冻结接口契约。

3. [07_当前实现与接口说明.md](./07_当前实现与接口说明.md)

当前系统已经实现了什么、对外结果字段有哪些、接口边界在哪里。

4. [01_系统设计文档.md](./01_系统设计文档.md)

系统架构、Agent 分工、通信机制、状态传递和共享记忆设计。

5. [04_方法部分.md](./04_方法部分.md)

写报告时的方法描述草稿，包括结构化通信、非文本状态、共享记忆和经验提炼。

6. [05_指标定义.md](./05_指标定义.md)

各类指标的定义和报告口径。

7. [06_运行命令汇总.md](./06_运行命令汇总.md)

当前各模式和数据集的运行命令摘要。正式运行仍以 [../RUNBOOK.md](../RUNBOOK.md) 为准。

8. [03_实验报告框架.md](./03_实验报告框架.md)

实验报告结构草稿，后续填入正式 openEuler 实验数据。

9. [02_部署文档草稿.md](./02_部署文档草稿.md)

部署说明草稿，后续需要根据 openEuler 复现过程补全。
