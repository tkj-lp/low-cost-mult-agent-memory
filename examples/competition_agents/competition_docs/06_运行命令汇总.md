# 运行命令汇总

## 1. 说明

本文档汇总当前比赛原型的主要运行命令。

正式实验命令以 [RUNBOOK.md](../RUNBOOK.md) 为准；本文档用于比赛文档编写时快速引用。

## 2. 依赖安装

Python 后端与本地模型依赖：

```powershell
cd D:\qq\low-cost-memory-integrate
.\.venv\Scripts\python.exe -m pip install -r examples\competition_agents\requirements.txt
```

如果需要 GPU 运行本地模型，请根据本机 CUDA 版本安装匹配的 PyTorch 轮子。当前本机实验使用的是 `torch 2.5.1+cu121`。

前端依赖由 `frontend/package.json` 管理：

```powershell
cd D:\qq\low-cost-memory-integrate\examples\competition_agents\frontend
npm.cmd install
```

## 3. 前端启动

后端服务：

```powershell
cd D:\qq\low-cost-memory-integrate
.\.venv\Scripts\python.exe examples\competition_agents\frontend_server.py --host 127.0.0.1 --port 8765 --echo-run-output
```

前端页面：

```powershell
cd D:\qq\low-cost-memory-integrate\examples\competition_agents\frontend
npm.cmd run dev
```

浏览器打开：

```text
http://localhost:5173/#/config
```
