# 运行命令汇总

## 1. 说明

本文档汇总当前比赛原型的主要运行命令。

正式实验命令以 [RUNBOOK.md](../RUNBOOK.md) 为准；本文档用于比赛文档编写时快速引用。

## 2. 前端启动

```powershell
python examples\competition_agents\frontend_server.py --host 127.0.0.1 --port 8765 --echo-run-output
```

## 3. baseline_text

### 3.1 TopiOCQA 连续任务

```powershell
python examples\competition_agents\run_demo.py `
  --experiment-mode baseline_text `
  --dataset-type continuous `
  --dataset-file examples\competition_agents\data\topiocqa_1_10turns.json `
  --show-memory `
  --show-latent `
  --show-state
```
