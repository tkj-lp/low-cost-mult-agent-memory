# 指标定义

## 1. 指标设计目标

本项目的指标定义围绕赛题要求展开，重点覆盖：

1. 通信开销
2. 非文本状态传递
3. 共享记忆复用
4. 任务效果
5. 运行效率

## 2. 通信相关指标

### 2.1 message_count

定义：

- Agent 间消息总次数

用途：

- 衡量多 Agent 协作过程中的消息往返规模

### 2.2 text_chars

定义：

- 文本通信总字符开销

用途：

- 近似衡量纯文本或结构化文本通信的成本

说明：

- 当前系统使用字符数而不是 tokenizer token 数
- 正式报告中应明确这一点

## 3. 非文本状态传递指标

### 3.1 latent_transfer_count

定义：

- embedding 或 latent state 形式的非文本状态传递次数

适用：

- `protocol_api_embedding`

### 3.2 latent_bytes

定义：

- 非文本状态传递的字节规模估计值

适用：

- `protocol_api_embedding`

### 3.3 hidden_state_refs / hidden_bytes

定义：

- hidden state 路径中的引用次数与数据规模

适用：

- `latent_hidden`

说明：

- 当前 hidden 与 protocol 路径的统计字段命名尚未完全统一
- 正式报告中需明确说明口径差异

## 4. 共享记忆指标

### 4.1 memory_hits

定义：

- 当前任务命中的共享记忆次数

### 4.2 memory_hit_rate

定义：

- 当前运行中共享记忆命中率

### 4.3 memory_write_count

定义：

- 当前任务写入记忆的总次数

### 4.4 experience_write_count

定义：

- 当前任务写入 experience memory 的次数

### 4.5 experience_hit_count

定义：

- 当前任务命中的 experience memory 次数

### 4.6 experience_used_count

定义：

- Reasoner 实际使用的 experience rule 数量

### 4.7 reuse_count

定义：

- 某条记忆被后续任务命中的次数

### 4.8 reuse_success_count

定义：

- 某条记忆在命中后被成功复用的次数

## 5. 效果与性能指标

### 5.1 exact_match

定义：

- 预测结果与标准答案的精确匹配结果

用途：

- 衡量问答或结构化任务的最终效果

### 5.2 elapsed_ms

定义：

- 单任务总耗时，单位毫秒

说明：

- 当前是整体运行时间口径
- 若后续需要强调“纯传输延时”，应单独定义并与总耗时区分

### 5.3 memory_growth

定义：

- 运行过程中共享记忆池的增长量

用途：

- 观察连续任务中记忆积累规模

## 6. 当前指标口径说明

当前系统已经能稳定导出：

- `message_count`
- `text_chars`
- `memory_hits`
- `memory_hit_rate`
- `memory_write_count`
- `experience_write_count`
- `experience_hit_count`
- `experience_used_count`
- `elapsed_ms`
- `exact_match`

## 7. 报告中建议的表格字段

建议正式实验表格至少包含：

- 方法名
- 数据集
- 任务数
- Exact Match
- 文本字符开销
- 非文本状态传递次数
- 非文本状态规模
- 总耗时
- 记忆命中率
- experience 命中数

## 8. 待后续统一的点

正式定稿前还建议进一步统一：

1. `latent_*` 与 `hidden_*` 两条路径的统计命名
2. 是否补充单独的“传输延时”指标
3. 是否增加消融实验专用指标
