# 当前实现与接口说明

## 1. 文档目标

本文档用于总结当前已经实现的比赛能力，以及主流程和超图记忆之间已经稳定下来的接口。

## 2. 当前已经实现的内容

### 2.1 多 Agent 协作

当前系统已经实现并跑通以下 Agent：

- `PlannerAgent`
- `RetrieverAgent`
- `ReasonerAgent`
- `SummarizerAgent`
- `ExecutorAgent`（CodeAct 场景）

### 2.2 双通信模式

当前系统已经支持：

- `baseline_text`
- `protocol_api`
- `protocol_api_embedding`

### 2.3 非文本状态传递

当前系统已经支持：

- embedding / latent state 引用传递
- hidden state 引用传递

### 2.4 共享记忆复用

当前系统已经支持：

- evidence memory 写入与检索
- experience memory 写入与检索
- experience rule 被 Reasoner 显式消费

### 2.5 连续任务验证

当前系统已经在以下任务组上完成连续任务验证：

- TopiOCQA 风格连续任务
- CodeAct 任务集

## 3. 当前接口边界

### 3.1 主流程侧负责

主流程当前负责：

- 什么时候写入记忆
- 什么时候检索记忆
- 如何把 experience 传给 Reasoner
- 如何统计指标
- 如何导出前端所需结果

### 3.2 超图记忆侧负责

超图记忆模块当前负责：

- memory record 的超图组织
- 记忆检索与排序
- 经验蒸馏辅助逻辑
- 后续 merge / dedup / prune 能力扩展

## 4. 当前稳定函数接口

以下函数视为当前稳定接口，后续如需优化，尽量不改函数名与参数名：

### `add_memory`

用途：

- 写入 evidence memory 或 experience memory

### `refine_memory`

用途：

- 基于任务案例与结果提炼 experience memory

### `search_memory`

用途：

- 按 query 检索共享记忆

### `increment_reuse_counts`

用途：

- 更新记忆的复用统计

## 5. 当前结果导出字段

当前前端与结果 JSON 已稳定使用以下字段：

- `final_answer`
- `messages`
- `metrics`
- `memory_hits`
- `experience_hits`
- `experience_rules`
- `execution_result`
- `latest_evidence_write`
- `latest_experience_write`
- `memory_refine_case`
- `memory_refine_debug`

## 6. 当前 experience memory 结构

experience memory 当前重点字段包括：

- `memory_id`
- `memory_type`
- `source_agent`
- `task_topic`
- `summary`
- `problem_pattern`
- `solution_pattern`
- `failure_pattern`
- `trigger_conditions`
- `supporting_evidence`
- `experience_source`
- `abstraction_note`
- `reuse_count`
- `reuse_success_count`

## 7. 当前已知待优化项

当前尚未完全收口的问题主要有：

1. experience 内容质量仍需继续稳定
2. trigger 条件仍可进一步收紧
3. hidden 与 protocol 的统计口径仍需统一解释
4. 最终正式实验数据仍需在 openEuler 环境下补跑
