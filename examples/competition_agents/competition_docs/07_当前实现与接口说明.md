# 当前实现与接口说明

更新时间：2026-06-24

本文档用于说明当前比赛原型已经实现了哪些能力，以及智能体主流程、超图记忆、前端展示之间已经稳定下来的接口。新对话接手时，应先读 `../AGENT_WORK.md`，再读本文档。

## 1. 当前已实现能力

- `PlannerAgent`
- `RetrieverAgent`

```text
Planner -> Retriever -> Reasoner -> Summarizer
```

## 2. 当前主流程

连续任务主流程：

```text
task
-> planner: 生成 plan / planner_focus
-> retriever: 检索 evidence memory / experience memory / context
-> reasoner: 消费 evidence + experience_rules，生成 answer_candidate
-> summarizer: 生成 final_answer，写回 evidence memory 和 experience memory
-> result export: 写出 run_result_json，供前端和报告使用
```

经验记忆写回节奏：

```text
write evidence memory
-> refine_memory(task case)
-> write experience memory
```

## 4. memory record 核心字段

基础字段：

- `memory_id`
- `memory_type`
- `source_agent`
- `created_at`
- `task_topic`
- `summary`
- `tags`

experience memory 关键字段：

- `problem_pattern`
- `solution_pattern`
- `failure_pattern`
- `trigger_conditions`
- `supporting_evidence`
- `confidence`
- `experience_source`
- `abstraction_note`
- `source_case`
- `experience_rule_card`
- `reuse_count`
- `reuse_success_count`

说明：

- `memory_type="evidence"` 表示事实/证据型记忆。
- `memory_type="experience"` 表示经验/策略型记忆。
- `experience_rule_card` 是 Reasoner 消费经验的结构化规则卡片。
- `source_case` 用于追踪经验来自哪一次任务结果。

## 6. 前端记忆指标依赖

前端超图记忆指标依赖后端返回的：

- `memory_evaluation.summary`
- `memory_evaluation.rows`
- task 级 `memory_hits`
- task 级 `memory_context`
- task 级 `expected_reuse`

其中 `memory_hits` 需要能被评估函数识别来源和工件类型。关键字段包括：

- `memory_id`
- `memory_type`
- `source_case`
- `trace`
- `task_topic`
- `supporting_evidence`
- `evidence`
- `state_refs`

如果候选记忆能显示但指标为 0，优先排查：

1. `memory_hits` 是否缺 `source_case` 或 `trace.task_meta.turn_id`。
2. `expected_reuse` 是否为空。
3. `memory_context` 是否没有包含实际使用的 `memory_id`。
4. `evaluate_run_reuse(...)` 是否无法判断命中是否相关。

## 7. hidden state 路径最新状态

hidden 路径主要文件：

- `examples/competition_agents/run_hidden_latent_samples.py`
- `examples/competition_agents/competition_agents/latent_hidden/local_model.py`
- `examples/competition_agents/competition_agents/latent_hidden/hidden_state.py`

当前 hidden 路径已经：

- 使用本地模型生成/推理。
- 提取 hidden state 或 pooled hidden 表征。
- 输出 `hidden_state_refs / hidden_bytes`。
- 接入 evidence + experience 双层记忆。
- 接入 `memory_refine_case / memory_refine_debug`。
- 修复了前端导出时清空 `memory_hits / memory_context` 的问题。
- 修复了 hidden 记忆条目缺少评估来源字段导致指标为 0 的问题。

最新修复后，需要重新跑 hidden 才能看到新指标。旧的 `run_result` 文件不会自动更新。

## 8. 前端展示接口

前端优先读取：

- `agent_views`
- `messages`
- `memory_hits`
- `memory_context`
- `execution_result`
- `latest_evidence_write`
- `latest_experience_write`
- `memory_refine_debug`
- `memory_evaluation`

前端不应自行构造记忆评估结论，应优先展示后端 `memory_evaluation`。
