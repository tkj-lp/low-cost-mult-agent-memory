## 实现与验证边界

- 以来源编号去重，保存完整实体、关系、否定、时间及限定；召回副本修改不会污染已存证据。
- 写回所有实际返回的来源事实，不因当前答案未用而丢弃；对话只关联实际使用的证据，其余来源按当前问题召回，不全部塞进交接。
- 来源事实在下游输出无效或接口失败时仍保留；失败答案不进入来源事实，也不记作成功对话。
- 规划省略查库开关时，有经过来源校验的记忆选择则先让检索角色判断；若属性未覆盖，仍能补查。没有按题号强制跳过查询。
- 首轮 `../memory_retention_api_three_20260925_r1` 因规划省略开关而失败，原始记录保留，不计入成功性能。
